子类与对象的关系：
1、当用子类的构造方法创建一个子类的对象时，不仅子类中声明的成员变量被分配了内存，而且父类的成员变量也都被分配了内存空间；

2、子类和父类在同一个包的情况下，虽然父类被分配了内存空间，但只将子类继承的那部分成员变量分配给子类对象，也就是子类将**不继承父类 private 类型的成员变量**；

3、子类和父类不在同一个包的情况下，**子类将不继承父类 private 和 友好 类型的成员变量**；

4、没有被子类继承的那些成员变量并不会占用内存空间，因为子类中可以操作从父类继承过来的方法，而那些方法里面是可以对那些成员变量进行操作的；

子类父类在同一个包内
//声明了一般类StudentFater
package Chapter_Five;
public class StudentFater {
        private int sum;
    int StudentID;
    protected int age;
    public String sex;
    protected void showPeopleMess() {
       sum = 1111;     //操作private类型的变量
       System.out.print(age+" 岁,性别："+sex+" sum的值="+sum+" StudentID的值："+StudentID);
    }   
}****

package Chapter_Five;
//继承同一个包中的类StudentFater 
public class Student extends StudentFater {
       public static void main(String[] args){
           Student st = new Student();
           //调用从父类继承过来的 protected、public、友好 类型的成员变量和方法
           //      st.sum = 1111;         //错误的，子类不能继承父类private类型的成员变量
           st.StudentID = 1234561;
           st.age = 18 ;
           st.sex = "男" ;
           st.showPeopleMess();
       }
} 

输出结果：18岁，性别：男sum的值=1111 StudentID的值：1234561

//声明了一般类StudentFater
package Chapter_One;
public class StudentFater {
        private int sum;
    int StudentID;
    protected int age;
    public String sex;
    protected void showPeopleMess() {
        sum = 1111;    //操作private类型的变量
       System.out.print(age+"岁,性别："+sex+" sum的值="+sum);
    }   
}

package Chapter_Five;
import Chapter_One.StudentFater;

//继承不同一个包中的类StudentFater 
public class Student extends StudentFater {
       public static void main(String[] args){
           //调用从父类继承过来的 protected、public 类型的成员变量和方法
             //    st.sum = 1111;         //错误的，子类不能继承父类private类型的成员变量 
         //    st.StudentID = 1234561; //错误的，子类不能继承父类 好友 类型的成员变量 
           st.age = 18 ;
           st.sex = "男" ;
           st.showPeopleMess();
       }
} 

输出结果：18岁，性别：男sum的值=1111
