# P1020 导弹拦截 — 题解（LIS 家族 + 三解法 + Dilworth）

> 洛谷 P1020，二分版为标准解，排名+线段树版当加餐。三解法对拍全一致（6000 组）。

## 题面问什么（两句话）

导弹高度序列 `a[1..n]`，问：

1. **一套系统最多拦截几枚** = **最长不上升子序列 LNDS**（允许相等：不能高于前一发，"高于"= 严格高才不行，所以相等可以）。
2. **最少要几套系统** = **最长严格上升子序列 LIS**（Dilworth 定理：最少不上升链覆盖数 = 最长严格上升子序列长度）。

所以答案第一问 = `max f`，第二问 = `max g`。

## 解法三足鼎立

### 0. 暴力 O(n²)（想清楚"以 i 结尾"）

```cpp
f[i] = 1 + max{ f[j] | j<i 且 a[j]>=a[i] }   // 不上升, 含相等
g[i] = 1 + max{ g[j] | j<i 且 a[j]<a[i]  }    // 严格上升, 不含相等
ans1 = max f, ans2 = max g
```

**坑**：f 是"以 i 结尾"向前看，不是向后改后面的。向后看的是"以 i 为最后一个"的标准 LIS 转移，两者方向相反。

### 1. 二分 tails 数组版（标准解）

核心是**"两毫米"** —— 允许相等 vs 禁止相等，只差换个比较器：

- `d1` 保持**不上升**：`upper_bound(d1, a[i], greater<int>())` 找**第一个严格小于 x** 的位置替换；找不到就 push_back。
  > 为什么 `upper_bound` + `greater`：期望序列不上升，要允许相等就找**第一个 `< x`**（把 `==` 的也留着），所以用 upper_bound（越过 ==）。
- `d2` 保持**严格上升**：`lower_bound(d2, a[i])` 找**第一个 ≥ x** 的位置替换。

```cpp
vector<int>d1, d2;
for(int i=1;i<=n;i++){
    int p1=upper_bound(d1.begin(),d1.end(),a[i],greater<int>())-d1.begin();
    if(p1==d1.size())d1.push_back(a[i]); else d1[p1]=a[i];
    int p2=lower_bound(d2.begin(),d2.end(),a[i])-d2.begin();
    if(p2==d2.size())d2.push_back(a[i]); else d2[p2]=a[i];
}
printf("%d\n%d\n",(int)d1.size(),(int)d2.size());
```

### 2. 排名 + 线段树版（加餐：把"向前看取 max"变成区间查询）

把"向前看 max"换成线段树做前缀/后缀 max 查询，需要**离散化**（值只有相对顺序重要）：

- 排序后 `rk[i] = lower_bound(b,a[i])+1` 得到排名（1..k）。
- 线段树下标 = 排名，每个位置存**以其为最后值的最长子序列长度**，点更新（取 max）+ 区间查询（取 max）。

```cpp
// ① 不上升: 当前排名 rk 之前(含)所有 >= rk 的接上 → 查询后缀 [rk, k]
f[i] = 1 + query(1,1,k, rk[i], k);  update(1,1,k, rk[i], f[i]);
// ② 严格上升: 接上排名严格小于 rk 的 → 查询前缀 [1, rk-1]
g[i] = 1 + query(1,1,k, 1, rk[i]-1); update(1,1,k, rk[i], g[i]);
```

**含端点 vs 不含端点的差别又一次出现**：①含 `rk` 自己（允许相等），②不含（严格）。

**为什么这里不用反转 rev？** 反转（reverse）是排名+BIT 才需要的技巧——BIT 只能查**前缀**和，想求后缀 max 就得把序列反过来求前缀。而线段树可以直接区间查询任意 `[L,R]`，所以既能查后缀 `[rk,k]` 又能查前缀 `[1,rk-1]`，**不需要反转**。

## 踩坑清单

1. **"不能高于前一发" = 允许等于** → 不上升用 `>=`、`upper_bound`、后缀含端点；严格上升用 `<`、`lower_bound`、前缀不含端点。混淆这里直接全错。
2. 线段树**存的是 max 不是 sum**：`seg=max(child)`，更新是 `max` 合并，不是相加。
3. 第二个 dp 要用**新的线段树**：`memset(seg,0,...)` 重置（②和①独立，不能共用累加结果）。
4. `rk[i]-1` 可能为 0（排名第 1 时没有更小的）——要特判，不能 query 无效区间（会区间外 return，但逻辑上 f[i] 应 =1）。
5. 输入：洛谷该题**无行数提示**，用 `while(scanf("%d",&x)==1)` 读到 EOF。
6. 离散化重复值：`lower_bound` 得到的是最小排名，相等值排到同一位置——这正是"允许相等"需要的（排序后相等的值共享一个排名槽位）。

## 武器库定位

| 难度 | 方法 | 复杂度 | 适用 |
|---|---|---|---|
| ⭐⭐⭐ | 暴力 O(n²) | O(n²) | n 小，练转移方向 |
| ⭐⭐⭐ | 二分 tails | O(n log n) | 标准、推荐、最简洁 |
| ⭐⭐⭐⭐ | 排名+线段树 | O(n log k) | 顺便复习离散化/线段树，为 P1908 逆序对做铺垫 |
