# P1873 [COCI 2011/2012 #5] EKO / 砍树 题解

> 洛谷 P1873 | 难度：普及/提高− | 知识点：二分答案

---

## 一、题目模型

n 棵树，高度 H1..Hn。锯子定一个高度 **h**：

- 比 h 高的树：从 h 处锯断，得到 `Hi − h` 米木头
- 比 h 矮的树：不动，贡献 0

要求砍下来的木头总长 **≥ m** 米，问 **h 最大**能定多少（整数）。

---

## 二、为什么是二分答案

1. **问的是一个数值最大多少**（锯子高度）
2. **验证容易**：给定高度 mid，"每棵树贡献多少、加起来够不够 m"秒算
3. **单调**（见下）

> 套路一模一样：**答案是一个数 + check 好写 + 可行性单调 → 二分答案。**

---

## 三、单调性

```
mid 升高 → 每棵树贡献 Hi−mid 变少 → 木头总量变少 → 可行性降低
```

所以"可行/不可行"依旧是真真假假一条分界线，找**最后一个真**（最大化）。

---

## 四、check 函数

```cpp
bool check(long long mid){
    long long total = 0;
    for(int i=0;i<n;i++){
        if(height[i] > mid) total += height[i] - mid;   // 只有比 h 高的树贡献
        // 矮树贡献 0，跳过即可
    }
    return total >= m;
}
```

## 五、完整 AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
long long n,m;
vector<long long>height;
bool check(long long mid){
    long long total=0;
    for(int i=0;i<n;i++){
        total += (height[i]-mid>0) ? (height[i]-mid) : 0;
    }
    return total>=m;
}
int main(){
    cin>>n>>m;
    height.resize(n);
    long long mx=0;
    for(int i=0;i<n;i++){
        cin>>height[i];
        mx=max(height[i],mx);      // 上界 = 最高树
    }
    long long l=0, r=mx;
    long long ans=0;
    while(l<=r){
        long long mid=(l+r)/2;
        if(check(mid)){
            ans=mid;               // 记录目前最好答案
            l=mid+1;               // 可行 → 锯得更高
        }
        else r=mid-1;              // 不可行 → 锯低点
    }
    cout<<ans;
    return 0;
}
```

## 六、和 P2440 木材加工：镜像兄弟题

| | P2440 木材加工 | P1873 砍树 |
|---|---|---|
| mid 意义 | 每段长度 | 锯子高度 |
| 每样东西贡献 | 每根原木 `Li / mid` 段 | 每棵树 `max(Hi−mid, 0)` 米 |
| 可行条件 | 段数 ≥ k | 木头 ≥ m |
| 单调方向 | mid↑ → 段数↓ | mid↑ → 木头↓ |
| 下界 | 1 | 0 |
| 上界 | 最长原木 | 最高树 |

**本质相同**：都是"mid 变大 → 收益单调下降 → 找满足约束的最大 mid"。学会一个，另一个只是把 check 换一行。

## 七、自测用例

**官方样例**（答案 36）：

```
5 20
4 42 40 26 46
```

> h=36：6+4+10=20 ≥20 ✓；h=37：5+3+9=17 <20 ✗ → 答案 36。

**全部砍不到 m**（最高树也只够一点，答案可能为 0 以下的最小可行值——h 可以取到树矮到 0，若 total 始终不够则 ans 为 0 时的最优即 0）：

```
3 100
5 6 7
```

> 总和 18 <100，任何 h 都不够 → 二分收敛后 ans=0（h=0 时总量最大仍 <100）。
