## 一、题目模型

n 根原木，长度 L1..Ln。要把它们切成**长度相同**的小段，至少得到 **k** 段。问每段**最长**能切多长？（切不出来输出 0）

---

## 二、为什么是二分答案（判别法）

三个特征全中：

1. **问的是一个数值最大多少**（每段长度）——不是"谁和谁"的关系题
2. **直接算难、验证容易**：直接求最长长度不好想，但给你一个长度 mid，"每根切几段、加够不够 k"秒算
3. **可行性单调**（见下节）

> **"答案是一个数 + 验证容易 + 可行性单调" = 二分答案。**
> 这是和"二分查找"（在数组里找已知的数）最本质的区别：答案是**我们猜出来**的。

---

## 三、单调性 —— 二分的命根子

```
mid 变大（切得越长） → 每根原木段数变少 → 总段数变少 → 可行性降低
```

所以"可行/不可行"的分布是**一段真接一段假**，中间只有一条分界线：

```
mid:  1  2  3 ...  X  X+1 ...
      真 真 真    真  假  假 ...
                  ↑
          要找的"最后一个真"（最大化）
```

这条"只有一条分界线"的性质就是**单调性**，没有它二分毫无意义。

---

## 四、check 函数：二分的眼睛

```cpp
bool check(long long mid){
    long long cnt = 0;
    for(int i=1;i<=n;i++){
        cnt += len[i] / mid;      // 整数除法 = 向下取整：切不完的段直接舍掉
    }
    return cnt >= k;
}
```

- 第 i 根原木 Li 按 mid 切 → `Li / mid` 段（向下取整）
- 总段数 `Σ (Li/mid)` ≥ k → mid 可行
- **check 写对了，二分就对了 90%**

## 五、完整 AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
vector<long long>len;
long long n,k;
bool check(long long mid){
    long long cnt=0;
    for(int i=1;i<=n;i++){
        cnt+=len[i]/mid;
    }
    return cnt>=k;
}
int main(){
    cin>>n>>k;
    len.resize(n+1);
    long long mi=0;                 // 坑 2：从 0 开始，让 max 真正生效
    for(int i=1;i<=n;i++){
        cin>>len[i];
        mi=max(len[i],mi);          // mi = 最长原木长度（安全上界）
    }
    long long l=1,r=mi;
    long long ans=0;                // 切不出 → 保持 0
    while(l<=r){
        long long mid=(l+r)/2;
        if(check(mid)){
            ans=mid;                // 记录目前最好答案
            l=mid+1;                // 可行 → 往更大的试
        }
        else {
            r=mid-1;                // 不可行 → 往小了试
        }
    }
    cout<<ans<<endl;
    return 0;
}
```

## 六、踩过的坑（亲测）

1. **`int cnt` 溢出（真实隐患）**：n≤1e5、每根≤1e8，mid=1 时 `cnt` 最多 **1e13**，int 装不下（max≈2.1e9），溢出后 `cnt>=k` 判断全错 → 大数据 WA。必须 `long long cnt`。小数据测不出来，只在数据大时炸。
2. **上界初始化 `mi=INT_MAX` 的坑**：`max(len[i], mi)` 里 len[i]≤1e8 永远小于 INT_MAX，mi 永不更新，`r` 一直是 2.1e9。碰巧不影响正确性（上界大点没事），但**不是本意**——你想要的是"最长原木"，应初始化 `mi=0`。
3. **上界用 `min`（最短原木）是错的**：答案是**可以超过最短木头的**。例：木头 [10,1]，k=3 → mid=3 可行（10/3=3 段），答案 3 > 最短木头 1。因为**可以完全无视最短那根**（它贡献 0 段，长木头照样凑够 k）。但答案**不能超过最长原木**（每段都来自某根原木）→ 所以上界用 max。
4. **死循环陷阱**：收缩区间必须让 l 或 r 真正动起来（`l=mid+1` / `r=mid-1`）。若写成 `l=mid`，l、r 差 1 且 check 为真时 mid 永远不变 → 死循环。

## 七、自测用例

**官方样例**（答案 2）：

```
3 7
10 5 1
```

> mid=2：10/2=5、5/2=2、1/2=0 → 7 段 ≥7 ✓；mid=3：10/3=3、5/3=1、1/3=0 → 4 段 <7 ✗ → 答案 2。

**切不出**（总长不够 k 段，答案 0）：

```
2 10
2 2
```

> 最多 2+2=4 段长度 1，< 10 → 答案 0。

**答案超过最短木头**（验证上界用 max 的理由，答案 3）：

```
2 3
10 1
```
