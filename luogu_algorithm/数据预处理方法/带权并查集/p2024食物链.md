# P2024 食物链 题解

> 洛谷 P2024 | 难度：蓝 | 知识点：并查集（扩展域 / 带权）

---

## 一、题目模型

三种动物构成一个 **3 环食物链**：

```
A 吃 B，B 吃 C，C 吃 A
```

关键性质：

- **每个物种只吃一个物种、只被一个物种吃**（方向性！）
- 所以"吃"关系是**有方向的函数**：给定猎物 → 唯一捕食者

输入 N 个动物编号 1..N，K 句话：

- `1 x y`：x 和 y 是同类
- `2 x y`：x 吃 y

**假话** = 编号越界 / x 吃自己 / 与前面的真话矛盾。统计假话条数。

## 二、解法一：带权并查集（模 3 报数）

### 权值的含义

只开 **N** 个节点，每个节点存一个**权值 `d[x]` = x 到根的距离**（模 3）：

```
d[x] % 3 = 0   x 与根同类
d[x] % 3 = 1   x 吃根
d[x] % 3 = 2   根吃 x（x 被根吃）
```

任意两点 x、y 的关系：`(d[x] - d[y]) % 3`

- 0 → 同类
- 1 → x 吃 y
- 2 → y 吃 x

输入语句的关系值 `rel = op - 1`：`0` 同类，`1` x 吃 y，`2` y 吃 x。

### 核心：find 必须"先递归，再累加"

```cpp
int find(int x){
    if(fa[x]!=x){
        int root=find(fa[x]);        // 先走到根
        d[x]=(d[x]+d[fa[x]])%k;      // 再把自己的权累加上去
        fa[x]=root;                  // 最后压缩
    }
    return fa[x];
}
```

顺序不能乱：不先递归，`d[fa[x]]` 还没更新成"到根的距离"，累加就错。

### 核心：merge 公式

两个根 `rx, ry`，要建立 x 到 y 的关系 `rel`：

```cpp
fa[rx]=ry;
d[rx]=(d[y]-d[x]+rel+k)%k;   // 0 同类，1 x吃y，2 y吃x
```

### 矛盾判断（同根时）

```cpp
if((d[x]-d[y]+k)%k != rel) ans++;
```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int k=3;
int ans=0;
int N,K;
vector<int>fa,d;
int find(int x){
    if(fa[x]!=x){
        int root=find(fa[x]);
        d[x]=(d[x]+d[fa[x]])%k;
        fa[x]=root;
    }
    return fa[x];
}
void merge(int x,int y,int rel){  //
    int rx=find(x);
    int ry=find(y);
    if(rx==ry){
        if((d[x]-d[y]+k)%k!=rel)ans++;
    }
    else {
        fa[rx]=ry;
        d[rx]=(d[y]-d[x]+rel+k)%k;// 0表示同类，1表示x吃y，2表示y吃x
    }
}
int main(){
    cin>>N>>K;
    fa.resize(N+1);d.resize(N+1);
    for(int i=1;i<=N;i++){
        fa[i]=i;
        d[i]=0;
}
    while(K--){
        long long op,x,y;
        cin>>op>>x>>y;
        if(x>N||y>N){ans++;continue;}
        if(x==y&&op==2){
            ans++;continue;
        }
        merge(x,y,op-1);
    }
    cout<<ans<<"\n";
    return 0;
}
```

## 三、解法二：扩展域并查集（分身术）

给每个动物开 **3 个分身**：

```
x        = x 自己          （同类域）
x + N    = x 的食物 / 猎物  （猎物域）
x + 2N   = x 的天敌         （天敌域）
```

总大小 `3*N`，并查集开 `fa[3*N+1]`。

### 合并规则

- `1 x y`（同类）：三个分身各自合并，身份完全一样
  ```cpp
  merge(x, y);
  merge(x+N, y+N);
  merge(x+2N, y+2N);
  ```

- `2 x y`（x 吃 y）：只并猎物/天敌两条边，x、y 自己**不**并
  ```cpp
  merge(y, x+N);      // y 进 x 的猎物域
  merge(x, y+2N);     // x 进 y 的天敌域
  ```

### 矛盾判断

- `1 x y` 假话：x 是 y 的食物 **或** x 是 y 的天敌
  ```cpp
  find(x)==find(y+N) || find(x)==find(y+2N)
  ```
- `2 x y` 假话：x 和 y 同类 **或** x 是 y 的食物
  ```cpp
  find(x)==find(y) || find(x)==find(y+N)
  ```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int ans=0;
int N,K;
vector<int>fa;
int find(int x){
    if(fa[x]!=x) fa[x]=find(fa[x]);
    return fa[x];
}
void merge(int x,int y){
    int rx=find(x),ry=find(y);
    if(rx!=ry) fa[rx]=ry;
}
int main(){
    cin>>N>>K;
    fa.resize(N*3+1);   // i 同类域, i+N 猎物域, i+2N 天敌域
    for(int i=1;i<=3*N;i++) fa[i]=i;
    while(K--){
        int op,x,y;
        cin>>op>>x>>y;
        if(x>N||y>N){ ans++; continue; }
        if(x==y && op==2){ ans++; continue; }
        if(op==1){
            if(find(x)==find(y+N) || find(x)==find(y+2*N)) ans++;
            else{
                merge(x,y);
                merge(x+N,y+N);
                merge(x+2*N,y+2*N);
            }
        }
        if(op==2){
            if(find(x)==find(y) || find(x)==find(y+N)) ans++;
            else{
                merge(y,x+N);
                merge(x,y+2*N);
            }
        }
    }
    cout<<ans<<"\n";
    return 0;
}
```

## 四、两解法对比（亲手验证的发现）

### 扩展域：只能发现"直接矛盾"

它靠"撞到同一个集合"判断，但合并只做直接操作，**无法跨链条推导**：

```
输入： 2 1 2   （1吃2）
      2 2 3   （2吃3）
      1 1 3   （1、3同类？）
```

3 环世界里 1→2→3 推出 1≠3，最后一句是**假话**。

- 带权版：`d` 记录了距离，算出 `d[1]-d[3]=2≠0` → 报假 ✅
- 扩展域版：合并后 1、3 没有共享分身 → **漏报** ❌

实测：带权输出 `2`，扩展域输出 `0`。

### 但是：扩展域能处理"同吃一猎物"

```
输入： 2 1 2   （1吃2）
      2 3 2   （3吃2）
      1 1 3   （1、3同类？）→ 真话
```

每个物种只吃一个物种 → **同一猎物 ⟹ 同一捕食者 ⟹ 同类**，`1≡3`。

扩展域能处理：两个捕食者都 merge 进了 `2+2N`（2 的天敌域）：

```
{2, 1+N, 3+N}    ← 2 同时进 1、3 的猎物名单
{1, 3, 2+2N}     ← 1、3 都进 2 的天敌名单 → 自动同队 = 同类 ✅
```

实测两版都输出 `1` ✅。

### 判断口诀

| 情况 | 扩展域 | 带权 |
|---|---|---|
| 直接矛盾（撞同一集合） | ✅ | ✅ |
| 同吃一猎物 → 同类（共享天敌域） | ✅ | ✅ |
| 链条传递 / 绕环推导 | ❌ | ✅ |

> **需要沿链条传递关系 → 用带权；只是直接冲突判断 → 扩展域/反集就够**（P1892 团伙那种反集同理）。

## 五、AC ≠ 算法对

扩展域版在洛谷能 AC，但上面"链条传递"的用例是完全合法的输入（编号不越界、没有自己吃自己）。说明**官方数据恰好没覆盖这类模式**。

> AC 只证明官方数据能过，不证明算法在所有合法输入下都正确。
> 做题时发现自己的 AC 代码"理论上不对"，先造反例，再判断是数据遗漏还是真 bug。
