## 二、一维前缀和

### 1\. 核心思想

提前预处理数组前 i 项的累加总和，将原本遍历区间求和的 O\(n\) 复杂度，优化为公式直接计算的 O\(1\)，适配多次区间查询场景。

### 2\. 公式定义

设原数组 `a[1~n]`，前缀和数组 `s[0~n]`

初始初始化：`s[0] = 0`

递推公式：`s[i] = s[i-1] + a[i]`

**区间 \[l, r\] 求和核心公式**：`sum = s[r] - s[l-1]`

### 3\. 完整标准模板代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> a(n + 1);
    vector<long long> s(n + 1, 0);

    // 构建前缀和数组
    for(int i = 1; i <= n; i++){
        cin >> a[i];
        s[i] = s[i - 1] + a[i];
    }

    // 多次区间查询
    while(m--){
        int l, r;
        cin >> l >> r;
        cout << s[r] - s[l - 1] << '\n';
    }
    return 0;
}
```

### 4\. 适用场景

静态数组（数组无修改、无更新），需要**多次查询任意区间总和**的题目。

### 5\. 易错踩坑清单

- 禁止0、1下标混用，会导致求和公式变形，极易计算错误

- 数组累加数值偏大时，int会直接溢出，求和数组必须用long long

- 1下标天然规避l=0的非法查询，无需额外边界判断

- 必须初始化s\[0\]=0，否则前缀和递推初始值错误

## 三、一维差分

### 1\. 核心思想

前缀和的逆运算，专门解决**多次区间批量加减、最后统一输出结果**的问题。通过打标记的方式代替暴力遍历修改，将多次O\(n\)修改优化为O\(1\)单次修改，最终O\(n\)还原数组。

核心逻辑：先批量完成所有区间修改打标，全部操作结束后，对差分数组求前缀和，还原出修改后的最终数组。

### 2\. 核心公式（区间 \[l,r\] 整体加 val）

```cpp
diff[l] += val;
diff[r + 1] -= val;
```

### 3\. 完整标准模板代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> a(n + 1);
    vector<int> diff(n + 2, 0); // 多开2位防越界

    for(int i = 1; i <= n; i++){
        cin >> a[i];
        diff[i] = a[i] - a[i - 1]; // 初始化差分数组
    }

    // 多次区间修改
    while(m--){
        int l, r, val;
        cin >> l >> r >> val;
        diff[l] += val;
        diff[r + 1] -= val;
    }

    // 前缀和还原最终数组
    for(int i = 1; i <= n; i++){
        diff[i] += diff[i - 1];
        cout << diff[i] << " ";
    }
    return 0;
}
```

### 4\. 适用场景

大量区间统一加减操作，无需实时查询中间结果，仅所有修改完成后输出最终数组。

### 5\. 易错踩坑清单

- 严禁边修改边还原，必须**全部修改完毕后再统一求前缀和**

- r\+1会超出数组范围，差分数组必须开n\+2富余空间

- 差分负责打标记修改，前缀和负责还原数组，顺序不可颠倒

- 初始化差分数组需遵循 `diff[i]=a[i]-a[i-1]`，不可直接赋值

## 四、二维前缀和

### 1\. 核心思想

基于**容斥原理**，预处理二维矩阵的前缀和，快速求解任意子矩阵的总和，规避双重循环暴力求和的高复杂度。

### 2\. 矩阵构造公式

`s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j]`

原理：累加上方、左方区域和，减去重复计算的左上角重叠区域，加上当前格子值

### 3\. 子矩阵查询公式

查询范围：左上坐标\(x1,y1\)，右下坐标\(x2,y2\)

`ans = s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]`

### 4\. 易错踩坑清单

- 容斥易错点：必须补回多减去的 `s[x1-1][y1-1]` 重叠区域

- 严格区分左上、右下坐标，禁止颠倒坐标顺序

- 二维矩阵求和数据量极大，前缀和数组必须用long long

- 全程1下标，避免边界0值导致的计算偏差

## 五、二维差分

### 1\. 核心思想

一维差分的二维拓展，用于**任意子矩阵批量统一加减数值**，是二维区间修改的最优解法，最后通过二维前缀和还原完整矩阵。

### 2\. 核心修改公式（子矩阵整体加val）

修改范围：左上\(x1,y1\)，右下\(x2,y2\)

```cpp
diff[x1][y1] += val;
diff[x1][y2 + 1] -= val;
diff[x2 + 1][y1] -= val;
diff[x2 + 1][y2 + 1] += val;
```

### 3\. 完整操作流程

初始化二维差分数组 → 批量完成所有子矩阵修改打标 → 执行二维前缀和 → 还原出最终矩阵

### 4\. 易错踩坑清单

- 四个坐标修改点缺一不可，漏写任意一个都会导致结果错误

- x2\+1、y2\+1易越界，二维数组需预留富余空间

- 必须所有修改完成后，再统一还原矩阵，禁止中途求值
