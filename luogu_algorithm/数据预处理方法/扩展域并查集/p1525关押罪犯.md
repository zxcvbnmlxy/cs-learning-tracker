# P1525 [NOIP2010 提高组] 关押罪犯 题解

> 洛谷 P1525 | 难度：蓝 | 知识点：贪心 + 扩展域并查集

---

## 一、题目模型

n 个罪犯，m 对矛盾关系，每对有怨气值 c。把所有人关进**两个监狱**（监狱内部的人互相不认识）。

目标是：让"同一个监狱内部的最大怨气值"**最小**。问这个最小值是多少。

---

## 二、贪心思路：先把最大的矛盾拆开

想让最大值最小，直觉就是**优先处理怨气大的矛盾**——大的必须拆到两个监狱里，剩给"最大值"的只会更小。

做法：按怨气值**从大到小**排序，从头处理每一对：

- 能拆开（放进不同监狱）→ 拆
- **拆不开了**（被前面的关系强制关进同一监狱）→ 这对的怨气值就是答案

```cpp
sort(e+1, e+m+1, [](const Edg &x, const Edg &y){ return x.c > y.c; });
```

**为什么贪心是对的**：第 i 对处理时，前面所有比它怨气大的对都被成功拆开了；如果这一对必须同狱，那么"能拆的都拆完"的情况下最小值就是这个 c。若一对矛盾 1 和矛盾 2（c1>c2）能同时拆开但被强制同狱，说明矛盾 1 的约束已经把矛盾 2 的两个端点绑死，而矛盾 1 更大，它才是真正决定答案的那个。

---

## 三、扩展域模型：分身术（i 本体 + i+n 敌人域）

开 **2n** 个节点：

```
1 ~ n     真实世界（罪犯本人）
n+1 ~ 2n  镜像世界（"我的敌人会被关进的监狱"聚集地）
```

规则只有两条：

```
merge(x, y+n);   // x 和 y 不在一个监狱
merge(y, x+n);   // y 和 x 不在一个监狱
```

语义："x 和 y 的敌人域同组" ⟺ "y 会被关进 x 不在的监狱" ⟺ "x、y 不同监狱"。

**矛盾判断**：如果 `find(x) == find(y)`，说明 x、y 被之前的约束强制进了同一监狱 → 拆不开了 → 输出当前的 c。

> "x 的敌人也是 y 的敌人 → x、y 同狱"这类跨链条的传递，由并查集的合并自动完成，不需要额外逻辑。（这跟 P1892 团伙的反集是同一个思想，只是 P1892 敌人域是"敌人聚集地"，这里是"另一个监狱"。）

## 四、完整 AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int MAXN=40010;
int fa[MAXN];
struct Edg{
    int a,b,c;
};
int find(int x){
    if(fa[x]!=x){
        fa[x]=find(fa[x]);
    }
    return fa[x];
}
void merge(int x,int y){
    int rx=find(x),ry=find(y);
    if(rx!=ry){
        fa[rx]=ry;
    }
}
int main(){
    int n,m;
    cin>>n>>m;
    vector<Edg>e(m+1);
    for(int i=1;i<=2*n;i++){
        fa[i]=i;              // 坑 1：必须初始化到 2n！
    }
    for(int i=1;i<=m;i++){
        cin>>e[i].a>>e[i].b>>e[i].c;
    }
    sort(e.begin()+1,e.end(),[](const Edg &x,const Edg &y){ return x.c>y.c;});

    for(int i=1;i<=m;i++){
        int x=e[i].a,y=e[i].b,val=e[i].c;
        if(find(x)==find(y)){
            cout<<val<<"\n";return 0;   // 拆不开 → 答案
        }
        else {
            merge(x,y+n);
            merge(y,x+n);
        }
    }
    cout<<0<<std::endl;       // 坑 2：全都拆得开 → 0
    return 0;
}
```

---

## 五、踩过的坑（亲测）

1. **fa 只初始化到 n**：merge 用到了 `y+n`（最大 2n），没初始化的节点 fa=0，全被并到根 0 上，导致提前误判矛盾。**必须 `for(i=1;i<=2*n;i++)`。**
2. **忘了全拆开的情况**：循环正常结束没矛盾时，答案应该是 0（所有矛盾都被拆到两个监狱里），必须输出 `0`。

## 六、判别法：怎么想到这题的

1. **两个监狱** → 只有两种"阵营" → 二选一 → 扩展域/反集
2. **"最大怨气值最小"** → 优先拆大的（贪心）→ 排序降序
3. 边处理边**查矛盾**（拆不开）→ 并查集

**思维链**：

```
两阵营二选一  →  扩展域并查集（i 本体 + i+n 阵营）
最大最小      →  排序贪心，从大到小拆
拆不开的第一对 = 答案
```

**和 P1892 团伙对比**：

| | P1892 团伙 | P1525 关押罪犯 |
|---|---|---|
| 镜像语义 | `n+i` = "我的敌人聚集地" | `n+i` = "另一个监狱" |
| 合并 | 朋友并本体；敌人互丢镜像 | 矛盾对互丢对方镜像 |
| 答案 | 不同根数量（团伙数） | 第一个拆不开的怨气值 |

## 七、自测用例

**官方样例**（答案 3512）：

```
4 6
1 4 2534
2 3 3512
1 2 28351
1 3 6618
2 4 1805
3 4 12884
```

> 推演：28351 最大先拆（1、2 分狱）；12884 拆（3、4 分狱）；6618 拆（1、3 → 与 1、2 组合出狱 1={1,3}? 由传递决定）；3512 时 2、3 被迫同狱 → 输出 3512。

**全部拆得开**（答案 0）：

```
2 1
1 2 100
```
