积木大赛（差分性质应用）
题意特征
给定最终高度序列，每次操作选择一段连续区间整体 +1，求达成目标最少操作次数。
和普通差分题型区分：普通差分是「输入修改，求最终数组」；本题是「已知最终数组，反向求最少操作」。
差分推导
设 
h[0]=0
，差分 
d[i]=h[i]−h[i−1]
。
所有大于 0 的差分值相加即为答案。
通俗理解：
当前位置比左边高，高出多少，就需要新增多少次操作；
当前位置低于左边，可复用之前的区间，无需新增操作。
核心代码框架（1 下标）

就是如果此时的位置比前一个高，就需要加上大于0的差分（两个之间的高度差），但如果要是比前面一个低，那么前面的区间操作就可以覆盖不用额外操作；

cpp
运行
#include<bits/stdc++.h>
using namespace std;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin>>n;
    vector<int>h(n+1);
    for(int i=1;i<=n;i++) cin>>h[i];
    long long ans=0;
    int last=0;
    for(int i=1;i<=n;i++){
        if(h[i]>last){
            ans += h[i]-last;
        }
        last = h[i];
    }
    cout<<ans<<'\n';
    return 0;
}
