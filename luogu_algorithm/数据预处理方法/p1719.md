题目描述：给出nxn带权矩阵边长n，求出最大带权矩阵的和，

原本的思路：就是求最大子矩阵，用二维前缀和求解，但是时间复杂度o（n的四次方）超时，

改进后思路：可以压缩矩阵为b[],同时上下枚举边界，将多行的同一列之和压缩到b[]里面，然后通过kadane算法求解

kadane算法：用于求解最大连续子数组，核心思路：dp[i]=max(dp[i],maxSeg+dp[i]);解读就是动态维护最大子数组，对于当前元素是单独开一个子数组，还是接在原来子数组后面，同理将本题矩阵数组压缩在b[]里面同样求解，利用矩阵连续性

枚举上边界up，枚举下边界down，将多行的同一列累加在b[k]内，这样子每一个b[k]就代表，以up为上边界，down为下边界的列矩阵，通过kadane算法求出最大连续子数组，即最大子矩阵；
时间复杂度o(n的三次方)

代码：

#include<bits/stdc++.h>
using namespace std;
const long long INF=-1e18;
int main(){
    int n;cin>>n;
    vector<vector<int>>a(n+1,vector<int>(n+1,0));
    vector<long long>b(n);
    for(int i=0;i<n;i++)
        for(int j=0;j<n;j++)cin>>a[i][j];
    long long ans=INF;
    for(int up=0;up<n;up++){
        fill(b.begin(),b.end(),0);
        for(int down=up;down<n;down++){
            for(int k=0;k<n;k++){
               b[k]+=a[down][k]; 
            }
            long long cur=0;
            long long maxSeg=INF;
            for(int k=0;k<n;k++){
            cur=max(b[k],cur+b[k]);
            maxSeg=max(maxSeg,cur);}
            ans=max(ans,maxSeg);
        }
    }
    cout<<ans<<"\n";
    return 0;
}
