# P1075 [NOIP2012 普及组] 质因数分解

> 知识点：试除法、√n 边界（质因数分解入门） / 难度：普及-

## 一、题面

已知正整数 n 是**两个不同质数**的乘积，求**较大的那个质数**。n ≤ 2×10⁹。

```
输入: 21          (21 = 3×7)
输出: 7           (较大的质因数)
```

## 二、核心洞察：p < √n，根本不用筛

设 n = p × q，p、q 都是质数且 p < q。

**两个不同质数**这个条件是解题钥匙：

```
p < q  ⟹  p·p < p·q = n  ⟹  p < √n
```

较小的质因子 p 一定在 √n 以内。所以：

- 从 2 开始试除，**第一个能整除 n 的 i 就是 p**；
- 答案 = n / p = q（较大的那个）。

## 三、为什么不需要筛法（刚学完线性筛也别顺手用）

| 对比 | P3383 线性筛 | P1075 这题 |
|---|---|---|
| 输入 | 一个范围 n + 1e6 次询问 | **就一个数** |
| 需求 | 预计算一次、查询 O(1) | 只算这一次 |
| 开销 | 筛到 n，需要线性筛 | 试除到 √n ≈ 44721 就够 |

√(2×10⁹) ≈ **44721**，从 2 试除到 44721 最多 4 万多次除法，一秒内跑完——**筛就是杀鸡用牛刀**。工具选型看数据形态，不是看题目主题。

## 四、边界三坑（本 session 踩/避开的）

### 坑 1：`i < sqrt(n)` 浮点做边界

- `sqrt()` 每轮重算，返回 double，浮点数比整数——不该出现在循环边界里；
- 整数边界就该用整数比较。

### 坑 2：`<` vs `<=` 是"题意在替你兜底"

`i < sqrt(n)` 是严格小于，`i*i <= n` 允许 i = √n。两者差在 i 恰好等于 √n 那一轮。这题因为 p < q，**√n 永远不是整数**，那一轮不存在——所以 `<` 侥幸没漏判。换一道不保证两因子不同的题，直接翻车。**别靠题目的特殊性命题。**

### 坑 3：`i*i <= n` 乘法溢出（和线性筛 `i*primes[j]` 双胞胎）

算 n = 2,147,483,647（int 上限），i 到 46341 时 `i*i = 2,147,488,281` 溢出 int，回绕成垃圾。这题 n ≤ 2×10⁹ 侥幸没到，但习惯必须是：

```cpp
i <= n/i      // 除法比较: 两个数都不超 n, 永不溢出
```

**这正是今天线性筛 `i*primes[j]<=n` → `i<=n/primes[j]` 的同一个逻辑。** 三天里第三次见"乘法比较溢出改除法"了（P1873、P2679、P3383、P1075）——下次循环边界比较，直接先写除法形式。

## 五、代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
ll n;
int main(){
    cin>>n;
    for(int i=2;i<=n/i;i++){     // 试除到 √n; i<=n/i 防溢出
        if(n%i==0){
            cout<<n/i<<"\n";     // 第一个整除 n 的 i = p, 答案 = n/p = q
            return 0;
        }
    }
    return 0;
}
```

## 六、验证

- 样例 `21` → `7` ✓
- 边界：n = 6 = 2×3 → 3 ✓；n = 1999999874（2×质数）→ 999999937 ✓
- **洛谷 AC**

## 七、思维总结

1. **读懂条件**："两个不同质数的乘积"直接给出 p < √n 的证明，解题钥匙藏在题面里；
2. **工具选型看数据形态**：单个数 + 无询问 → 试除；范围 + 海量询问 → 筛。先估复杂度再挑工具；
3. **边界习惯**：循环上界用整数比较、用除法形式防溢出——这条已经刻进肌肉记忆了。
