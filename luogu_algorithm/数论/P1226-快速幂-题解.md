# P1226 【模板】快速幂 | 取余运算

> 知识点：快速幂（倍增思想入门） / 难度：入门-普及

## 一、题面

给定三个正整数 a、b、p（都到 10⁹ 量级），求 **a^b mod p**。

```
输入: 2 10 9
输出: 2^10 mod 9 = 7      (2^10=1024, 1024%9=7)
```

## 二、朴素做法为什么不行

直接 `for` 循环 b 次相乘：
1. **超时**：b 最大 10⁹，循环 10⁹ 次必炸；
2. **溢出**：a^b 是天文数字（10⁹ 的 10⁹ 次方），`long long` 根本装不下。

两个问题各有解法，但核心是压缩循环次数。

## 三、关键数学性质（先解决溢出）

> **(x × y) mod p = (x mod p) × (y mod p) mod p**

意思是**每一步乘完立刻取模**，全程每个数字都不超过 p 的量级，`long long` 永远装得下。
这是"模运算的分配律"，是所有取模题的万用底子。

## 四、核心思想：指数折半、底数平方（解决超时）

把指数 b 拆成二进制。例：b = 13 = 1101₂

```
a^13 = a^8 · a^4 · a^1
     = (a^4)² · (a^2)² · a
```

**关键动作：指数每次折半，底数每次平方。**

- 第 k 轮手里的 `base` 是 a^(2^k)，它是上一轮的 `base` **平方**得来的 → 一次乘法算一个"平方档位"；
- 指数 b 的那一位是 0 还是 1，决定要不要把当前档位乘进答案 → 用**按位与**看二进制最低位；
- 指数右移一位看下一位。

这样 b 次乘法被压成 **log₂b 轮**。10⁹ → 约 30 轮。

## 五、模板代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
int main(){
    ll a,b,p;
    cin>>a>>b>>p;
    ll base=a%p;    // 档位: 当前是 a^(2^k), 每轮自己平方
    ll ans=1;       // 累乘结果
    ll exp=b;       // 指数的剩余部分, 每轮右移一位
    while(exp>0){
        if((exp&1)==1) ans=ans*base%p;  // ① 当前位是1→乘进答案(取模!)
        base=base*base%p;               // ② 档位平方: a^(2^k)→a^(2^(k+1))
        exp=exp>>1;                     // ③ 指数右移, 看下一位
    }
    cout<<a<<"^"<<b<<" mod "<<p<<" = "<<ans<<endl;  // 注意格式空格!
    return 0;
}
```

## 六、本 session 踩的三个坑

1. **`ans` 忘记取模**：只给 `base` 取模，`ans*=base` 一路不模 → ans 变成 a^b 真实大数 → 溢出 + 答案错（样例输出 16 不是 7）。**两个因子都要每轮取模。**
2. **`exp&1==1` 优先级陷阱**：C++ 里 `==` 优先级比 `&` 高，`exp&1==1` 实际是 `exp & (1==1)` = `exp & 1`——**碰巧能工作**，但靠运气。正规写法 `(exp&1)==1` 或直接 `if(exp&1)`。位运算与逻辑/比较运算符混用**必须加括号**。
3. **输出格式**：洛谷要求 `a^b mod p = 7`（**等号两边各一个空格**），评测逐字符比对，差一个空格就 WA。

## 七、验证

- 样例 `2 10 9` → `2^10 mod 9 = 7` ✓（AC）
- 快速幂 vs 暴力 O(b) 对拍 **20000 组全过**（覆盖 b=0、p=1、奇偶边界）

## 八、思维总结（套路）

快速幂的套路三步：**① 数学性质压大小（取模分配律）→ ② 指数拆二进制 → ③ 指数折半、底数平方、按位决定是否乘**。

这个"按二进制拆"的思维在后续**矩阵快速幂**（递推加速）、**欧拉降幂**（指数巨大时）里都会复用——先把底子打好。
