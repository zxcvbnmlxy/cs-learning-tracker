# P1082 [NOIP2012 提高组 D2T1] 同余方程

> 知识点：扩展欧几里得（exgcd）的第一个实战——求逆元 / 难度：普及+/提高

## 一、题面

给定**互质**的正整数 a, b（2 ≤ a,b ≤ 2×10⁹），求同余方程

$$ax \equiv 1 \pmod b$$

的**最小正整数解** x。

```
输入: 3 10
输出: 7        (3×7=21 ≡ 1 mod 10 ✓)
```

## 二、先补概念：同余 ≡ 是什么

**定义**：`a ≡ b (mod m)` ⟺ a 和 b 除以 m 的**余数相同**。

**时钟类比**：mod 12 的世界里，13 点和 1 点是同一个时刻——差了一整圈（12 的倍数）。

**做题常用的等价说法**：

> a ≡ b (mod m) ⟺ **m 能整除 (a-b)** ⟺ a - b 是 m 的倍数

验证 `17 ≡ 1 (mod 8)`：17÷8 余 1、1÷8 余 1 ✓；等价说法：17-1=16，8|16 ✓。两条路哪条方便走哪条。

## 三、核心洞察：同余方程 = 线性丢番图方程

翻译我们的题：

```
ax ≡ 1 (mod b)      "ax 和 1 除以 b 余数相同"
⟺ b | (ax - 1)      "b 整除 ax-1"
⟺ ax - 1 = b·y      "ax-1 是 b 的 y 倍"
⟺ ax - b·y = 1      （移项）
```

这就是 **exgcd 解的方程** `ax + by = 1`，只是 y 前是负号。但 y 是任意整数，`-b·y = b·(-y)`——**负号吞进 y 里**，直接 `exgcd(a,b,X,Y)` 就好，X 就是我们要的 x（Y 的正负无所谓，我们不关心）。

**为什么一定有解**：a、b 互质 ⟹ gcd = 1，裴蜀定理保证 ax+by=g 对任意 g 有解（上一题学过）。

## 四、最小正解怎么来：X 加/减任意个 b 还是解

exgcd 解出的 X 可能为负、也可能大于 b。但注意：

```
a(X + b) = aX + ab ≡ aX ≡ 1 (mod b)
```

X 加/减任意个 b 还是解。又因为**互质 ⟹ 解在 mod b 下唯一**，所以答案就是 X 在 [1, b-1] 里的那个代表元：

```cpp
cout << (X % b + b) % b << "\n";   // 先归一化进 [0,b-1], +b 再取模, 得到 [0,b-1]; 互质保证不会得 0
```

`(X%b+b)%b` 是"取最小非负余数"的标准姿势（C++ 的 % 对负数给负结果，需要手动修）。

## 五、本 session 踩的坑（全 ll 化）

| 坑 | 错法 | 后果 | 正解 |
|---|---|---|---|
| 逗号运算符 | `cin>>a,b;` | 逗号是运算符：`(cin>>a), b;` 只读 a，b 保持 0 → exgcd(a,0) 走基例 → `(X%b+b)%b` 除零崩溃 | `cin>>a>>b;` |
| temp 混 int | `int temp=y;` | 系数最坏 ~2×10⁹（斐波那契数对），离 int 上限 2.147×10⁹ 只差 7%，**侥幸没炸**——但这是雷 | `ll temp=y;` |
| 参数混 int | `int exgcd(int a,int b,...)` | 全局 ll 塞进 int 同样"刚好塞得下" | 全函数 ll |

**原则**：一个计算链里，最宽的类型决定全程。系数可达 ~2×10⁹、差 7% 就爆 int——既然 x、y 是 ll，temp、参数、返回值就全 ll，一个 int 都不留。

## 六、代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
ll exgcd(ll a,ll b,ll &x,ll &y){
    if(b==0){ x=1,y=0; return a; }
    ll g=exgcd(b,a%b,x,y);
    ll temp=y;
    y=x-(a/b)*y;
    x=temp;
    return g;
}
int main(){
    ll a,b,X,Y;
    cin>>a>>b;
    exgcd(a,b,X,Y);
    cout<<(X%b+b)%b<<"\n";
    return 0;
}
```

## 七、验证（对拍）

- 样例 `3 10` → `7` ✓
- **对拍 40 万组全过**：小范围（a,b ≤ 1000，b ≤ 101）20 万组 vs 暴力枚举（从 1 试到 b-1 第一个满足 `(a*x)%b==1` 的）逐组一致；大范围（a,b 到 2×10⁹）20 万组验证 ①`(a*ans)%b==1` ②`1≤ans<b`（互质 ⇒ 解唯一，落在 [1,b-1] 即已证最小）。

## 八、思维总结 & 预告

1. **同余符号只是"余数相等"**，翻译成整除/方程是解题第一动作；
2. **exgcd 的通用用法**：任何 `ax + by = c`（c 是 gcd 的倍数）都能解，符号差异吞进系数里；
3. **最小正解标准化**：`(X % b + b) % b`，记住这个姿势，逆元、CRT 到处用；
4. **全 ll 化**：系数量级贴着 int 上限，混 int 就是埋雷。

> **预告**：`ax ≡ 1 (mod b)` 解出的 x，在数学里有个专门名字——**a 关于模 b 的乘法逆元**。下一步我们用逆元解决真正的除法取模问题。
