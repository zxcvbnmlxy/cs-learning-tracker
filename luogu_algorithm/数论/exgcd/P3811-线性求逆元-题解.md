# P3811 【模板】模意义下的乘法逆元

> 知识点：逆元的线性递推（O(n) 求所有逆元）/ 难度：普及+/提高

## 一、题面

给定质数 p（p < 2×10⁷）和 n（n ≤ 3×10⁶，且 n < p），求 **1~n 每个数**在 mod p 下的逆元，输出 n 行。

```
输入: 10 13
输出: 1 7 9 10 8 11 2 5 3 4
```

为什么 n < p？p 是质数 ⟹ 1~p-1 全和 p 互质 ⟹ 全有逆元（必要条件自动满足）。

## 二、为什么不能一个个 exgcd

n = 3×10⁶，每个 exgcd 递归 20+ 层、全是取模除法 → 总共 **~10⁸ 次操作**，1 秒顶不住。

哲学和线性筛一样：**别重新算，由已知推未知**——由小逆元推出大逆元，一趟 O(n)。

## 三、核心推导：p 的整除带余是唯一纽带

想求 inv[i]，先问：**怎么把 i 和一个更小的数扯上关系？** 唯一自然的式子是整除带余：

```
p = k·i + r        k = p/i,  r = p%i      (0 < r < i)
```

为什么这条有用？因为 **p 在 mod p 下是 0**，左边整个 p 消失：

```
k·i + r ≡ 0  (mod p)
```

两边乘 i⁻¹（i < p 且 p 质数 ⟹ 逆元存在 ✓）：

```
k + r·i⁻¹ ≡ 0
r·i⁻¹ ≡ -k
i⁻¹ ≡ -k·r⁻¹     =  -(p/i)·inv[p%i]  (mod p)
```

**关键**：`p%i < i`（余数小于除数），所以 `inv[p%i]` 是**已经算好**的逆元——递推成立。

## 四、代码里的等价写法

`-(p/i)·inv[r]` 带着负号，模 p 下写成 `(p - p/i)·inv[p%i]` 更干净——因为 `p ≡ 0 (mod p)`，`p - p/i ≡ -(p/i)`：

```cpp
inv[i]=(ll)(p-p/i)*inv[p%i]%p;
```

## 五、p=7 走一遍

k=p/i, r=p%i, inv[i]=-k·inv[r] mod 7：

| i | k | r | inv[i] | 验算 |
|---|---|---|---|---|
| 1 | — | — | 1 | 1×1≡1 ✓ |
| 2 | 3 | 1 | -3·1≡4 | 2×4=8≡1 ✓ |
| 3 | 2 | 1 | -2·1≡5 | 3×5=15≡1 ✓ |
| 4 | 1 | 3 | -1·5≡2 | 4×2=8≡1 ✓ |
| 5 | 1 | 2 | -1·4≡3 | 5×3=15≡1 ✓ |
| 6 | 1 | 1 | -1·1≡6 | 6×6=36≡1 ✓ |

每一步用已算好的 inv[r]，一行 O(1) 推出下一个。

## 六、坑

| 坑 | 后果 | 正解 |
|---|---|---|
| `(p/i)*inv[p%i]` 乘积 ~4×10¹⁴ 爆 int | 答案全乱 | 乘一个因子转 ll：`(ll)(p-p/i)*...` |
| 3×10⁶ 行输出不用快读 | TLE | `ios::sync_with_stdio(0)` + `'\n'` |

## 七、验证（对拍）

- 样例 `10 13` → `1 7 9 10 8 11 2 5 3 4` ✓
- ① 小范围：随机质数 p<20000、随机 n，**每组全 i** 和 exgcd 逐个对照，2000 组全过；
- ② 真实规模 n=3×10⁶、p=998244353：全 i 满足 `i·inv[i]≡1`，2000 个随机点 exgcd 对照通过。

## 八、思维总结 & 关联

1. **和 exgcd 同源**：都靠"线性组合 + 欧几里得式缩小"。exgcd 是**欧几里得递归**（a%b 不断变小），线性递推是**整除带余**（p%i 不断变小）——本质都是把问题归约到更小的数；
2. **单个数逆元的两种求法**：exgcd（P1082）或**费马小定理** `inv[a]=a^(p-2) mod p`（p 质数，配快速幂）——但求**全部**逆元时线性递推 O(n) 完胜；
3. **用逆元做除法**：模意义下 `a/b ≡ a·b⁻¹ (mod p)`，除法唯一替代品。

> 承接 P1082（exgcd 求单个逆元）→ 本篇（线性递推求全部）。数论 exgcd→逆元 主线收官。
