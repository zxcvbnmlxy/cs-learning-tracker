# P1433 吃奶酪 题解（状压 DP 入门教程）

> 2026-08-22 完成 | 状态压缩 DP（状压 DP）| 第一道状压，也是「TSP 旅行商」的同款模板
> 一句话定位：**n 块奶酪（n≤15）各访问一次，求从原点出发的最短路径。排列数 n! 爆炸，用二进制集合压缩到 2ⁿ。**

---

## 〇、题面

- n 块奶酪，每块有坐标（**坐标可能是负值**）。
- 从原点 `(0,0)` 出发，每块奶酪**恰好访问一次**，求最短总路程。
- 输出保留 **2 位小数**。

**样例**：
```
3
1 1
1 0
0 1
```
答案 `3.41`（路线：原点 →(1,0) →(1,1) →(0,1)，1 + 1 + √2 ≈ 3.41）

---

## 一、为什么暴力不行 → 撞上 n!

直接的想法：**枚举访问顺序（排列）**，对每个排列累加距离，取最小。

- 排列数 = **n!**，n=15 → 15! ≈ **1.3 × 10¹²**，跑不完。
- 但注意：n 只有 **15**，2¹⁵ = 32768 很小。

> 这个「n 很小但排列爆炸」的组合，是状压 DP 的经典信号。

---

## 二、核心观察（推导的起点）

问自己一个问题：

> **我站在奶酪 i、已经吃了集合 S，往后还要走多远——它取决于什么？**

- 只取决于两件事：**吃了哪些（集合 S）+ 现在停在哪（i）**。
- **前面走的顺序不重要！** 先吃 A 再吃 B，还是先 B 再 A——只要最后停在同一个 i、吃了同一堆奶酪，后面的最优路线完全一样。

→ 这就是**最优子结构 + 无后效性**：状态只记「集合 + 停点」，可以 DP。

> 关键跳跃：**把「吃了哪些」从「顺序」里解放出来。** 顺序是 n! 种，集合只有 2ⁿ 种。

---

## 三、集合怎么存？→ 二进制位（状压的灵魂）

每块奶酪只有「吃了/没吃」两种状态 → 正好对应二进制的 **1 / 0**。

用一个整数 `mask` 表示集合，第 i 位 = 1 表示第 i 块已吃：

```
mask = 5 = 101₂  →  第 0 位、第 2 位是 1  →  吃了奶酪 0 和 2
```

**为什么 n ≤ 15 是关键**：状态数 = 2ⁿ。n=15 → 32768；n=30 → 10 亿，炸。**n ≤ 20 是状压 DP 的适用边界。**

### 三个位运算（背下来，就这三个）

| 操作 | 代码 | 含义 |
|---|---|---|
| 判断 i 在不在集合 | `mask & (1<<i)` | 非 0 = 在 |
| 把 i 加入集合 | `mask \| (1<<i)` | 第 i 位置 1 |
| 全集 | `(1<<n) - 1` | n 位全 1 |

补充两个常客：
| 把 i 移出集合 | `mask & ~(1<<i)` | 第 i 位置 0 |
| 枚举集合内每个 i | `for(i=0;i<n;i++) if(mask>>i & 1)` | 逐个检查位 |

---

## 四、DP 定义（题眼）

```
dp[mask][i] = 已吃集合 = mask、当前停在奶酪 i 的最小路程
```

- **第一维 mask**：状态压缩的核心——用二进制位存集合；
- **第二维 i**：压缩不掉的信息「停在哪」——转移必须知道现在在哪，才能算下一步距离。

> 状压 DP 的数组设计公式：`dp[mask][转移必须的附加信息]`。附加信息通常很小（一个下标、一个最后字符），mask 是主角。

---

## 五、初始化（第一块）

第一步之前只能在原点，所以「只吃了奶酪 i」的状态，距离就是**原点 → i**：

```
dp[1<<i][i] = sqrt(x[i]² + y[i]²)      // 每个点都可能是第一块
```

> `1<<i` 就是「只有一个位亮、代表只吃 i 的集合」。

---

## 六、转移方程（怎么推导出来）

从 `dp[mask][i]`（已吃 mask，停在 i）出发，要去吃下一块 **j**：

1. **前提**：j 还没吃 → `mask` 的第 j 位是 0；
2. **吃进去**：新集合 = `mask | (1<<j)`，停在 j；
3. **路程** = `dp[mask][i] + dist[i][j]`；
4. **可能多条路到达同一状态**（比如先 A 再 B，或先 B 再 A）→ 取 min：

```
只当 (mask & (1<<j)) == 0 时：
dp[mask | (1<<j)][j] = min( dp[mask | (1<<j)][j],  dp[mask][i] + dist[i][j] )
                          ↑ 已有值（别的路）        ↑ 新路线（这条路）
```

> 记忆口诀：**「自己有 i，目标没 j，路走得通」**——三个 continue 条件。
> - 条件 1：mask 里有 i（没吃它怎么停在那）
> - 条件 2：dp[mask][i] ≠ 无穷（这状态真能到）
> - 条件 3：mask 里没有 j（吃了的不能重复吃）

---

## 七、答案

- 全吃完 = mask = `(1<<n) - 1`；
- 最后停在**哪块都行** → 对所有 i 取 min：

```
ans = min_i  dp[(1<<n)-1][i]
```

> ⚠️ 不能直接输出 `dp[(1<<n)-1][n-1]`——最后一块不一定是第 n-1 块！

---

## 八、复杂度

| | 时间 | 空间 |
|---|---|---|
| 总量 | O(n² · 2ⁿ) | O(n · 2ⁿ) |

n=15 → 15² × 32768 ≈ **7.4 × 10⁶**，秒过。空间 15 × 32768 个 double ≈ 4MB。

> 相比 n! 的 10¹²，2ⁿ 的 3×10⁴ 是降维打击——**这就是「状态压缩」四个字的含义：把排列压成集合。**

---

## 九、你踩的坑（必考细节）

### 坑 1：`&` 的优先级比 `==` 低！（第一大坑）

```cpp
if(mask & (1<<i) == 0)      // ❌ 实际是 mask & ((1<<i)==0)
```
- `(1<<i) == 0` 恒等于 **false = 0**；
- 整句变成 `mask & 0` 恒等于 **0**；
- `if(0) continue` → **条件永远不触发，是死代码**！

条件 3 同理会变成 `mask & 1`，只查第 0 位，j 是谁根本不管。

**修复：加括号，逼编译器先与再比较：**
```cpp
if((mask & (1<<i)) == 0)  continue;    // ✅
if((mask & (1<<j)) != 0)  continue;    // ✅
```

### 坑 2：答案没取 min

`dp[(1<<n)-1][n-1]` 只查停在最后一块的路线 → 必须 `for` 循环对 i 取 min。

## 十、状压 DP 通用知识点（手写笔记用）

### 模板五步

1. **判题**：n ≤ 20、每个元素只有两种状态、要枚举「子集/排列」→ 用状压 DP。
2. **三个位运算**：判断 `&`、加入 `|`、全集 `(1<<n)-1`。
3. **dp 定义**：`dp[mask][附加]`——mask 存集合，附加存转移必须的「停在哪/最后是谁」。
4. **转移**：永远从 `mask` 走向 `mask|(1<<j)`（只变大）→ **mask 从小到大循环就是拓扑序**，不需要记忆化搜索。
5. **答案**：看题要什么，通常是「全集状态 + 取 min」。

### 和其他 DP 的关系

状压 DP 不是新物种，就是**普通 DP，只是把「集合」这一维压进二进制的位里**。n! 太慢时，2ⁿ 就成了救星。

### 转移方向的拓扑序（为什么 mask 从小到大就行）

`mask | (1<<j)` 一定 > `mask`（OR 进一个 1 位，数值只增不减）→ 处理 mask 时，所有能转移到它的更小状态都已经算完。**这就是从小到大循环合法的原因。**
