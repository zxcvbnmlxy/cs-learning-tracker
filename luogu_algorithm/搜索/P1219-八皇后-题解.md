# P1219 八皇后 题解

> 2026-08-16 完成 | DFS 回溯 + 剪枝 | n≤13 最坏 0.28s
> 一句话定位：**DFS 一行放一个皇后，用三个标记数组剪枝，回溯还原状态枚举全部方案。**

---

## 一、题目翻译

n×n 棋盘放 n 个皇后，任意两个皇后**不能同行、同列、同对角线**。
要求输出**前 3 种解法**（每种解法输出每行皇后的列位置）+ **总方案数**。

---

## 二、为什么是 DFS 而不是 BFS（先想清楚）

| | DFS | BFS |
|---|---|---|
| 目标 | **枚举所有解** | 找最短/最少步数 |
| 工具 | 递归（系统栈） | 队列 |

八皇后要的是"所有合法方案"（数个数 + 输出前 3），不是"最短路径"。
而且每层的可选状态很多（每行试 n 列），用 BFS 层层展开队列会爆炸。
→ **枚举全部方案选 DFS，这是第一判断。**

---

## 三、核心：三个标记数组怎么建模"冲突"

皇后的攻击范围：横、竖、两条对角线。同行不用管（我们**一行放一个**，天然无同行）。

三个标记数组：

| 数组 | 下标含义 | 说明 |
|---|---|---|
| `col[j]` | 第 j 列是否已占用 | 竖线冲突 |
| `udg[row-j+n]` | 主对角线 \ 是否已占用 | 同一条 \ 上 `row-j` 相等 |
| `dg[row+j]` | 副对角线 / 是否已占用 | 同一条 / 上 `row+j` 相等 |

**为什么下标是 `row-j+n` 和 `row+j`？**
- 主对角线 \：所有格子满足 `row - col = 常数`（如 (1,1)(2,2)(3,3) 的 row-col=0）。
  用 `row - j` 当索引，但 row-j 可能是负数（1-n ≤ row-j ≤ n-1），**+n 平移**保证下标 ≥1。
- 副对角线 /：所有格子满足 `row + col = 常数`（如 (1,3)(2,2)(3,1) 的 row+col=4）。
  用 `row + j` 当索引，天然 ≥2，无需平移。

> 记忆：**主对角线看差值（row−j），副对角线看和值（row+j）**。这是八皇后最核心的抽象，考场上背住直接写。

---

## 四、DFS 流程

```
dfs(row) 处理第 row 行：
├─ 如果 row > n：找到一个方案 → cnt++，cnt≤3 时输出
├─ 否则：对第 row 行，尝试每一列 j（1..n）：
│   ├─ 如果 col[j]、dg、udg 都空闲：
│   │   ├─ 放置：graph[row]=j，三个标记置 true
│   │   ├─ 递归：dfs(row+1)
│   │   └─ 还原：三个标记置 false（回溯！）
```

---

## 五、代码（重点注释版）

```cpp
#include<bits/stdc++.h>
using namespace std;
int cnt=0;                       // 方案总数
int n;
bool col[20]={false};            // 列是否占用
bool udg[40]={false};            // 主对角线 \ 是否占用（row-j+n 平移防负下标）
bool dg[40]={false};             // 副对角线 / 是否占用（row+j）
int graph[20];                   // graph[row]=该行皇后所在列

void dfs(int row){
    if(row>n){                   // 放了 n 行，找到一个完整方案
        cnt++;
        if(cnt<=3){              // 只输出前 3 个
            for(int i=1;i<=n;i++)
                cout<<graph[i]<<((i==n)?"\n":" ");
        }
        return ;                 // ★ 记得 return！否则会继续跑下面的 for
    }
    for(int j=1;j<=n;j++){       // 第 row 行，尝试放在每一列
        if(!col[j]&&!udg[row-j+n]&&!dg[row+j]){   // 三处都不冲突
            graph[row]=j;                           // 放置
            col[j]=dg[row+j]=udg[row-j+n]=true;     // 打标
            dfs(row+1);                             // 递归下一行
            col[j]=dg[row+j]=udg[row-j+n]=false;    // ★ 回溯还原
        }
    }
}
int main(){
    cin>>n;
    dfs(1);
    cout<<cnt;
    return 0;
}
```

---

## 六、两个关键细节

1. **回溯还原必须在递归之后**：`dfs(row+1)` 返回后，把标记还原成 `false`，否则这一列在兄弟分支里没法再放。**忘了还原 = 漏解。**
2. **`return;` 不能省**：找到方案后如果直接往下走 for 循环，虽然 n 个皇后放完时 `col` 全 true 循环进不去（"侥幸安全"），但逻辑上依赖巧合。**显式 return 才和意图一致。**

---

## 七、复杂度

- 剪枝后实际状态数远小于 n!，n=13 最坏跑 ~0.28s，AC。
- 不做剪枝（裸枚举 n 行各放一列）是 n^n，n=13 直接 TLE。

---

## 八、变式思考

1. **N 皇后变体**：求**对称**方案 / 用**位运算**做标记（整型变量当 bool 数组，`x&(-x)` 取最低位）——竞赛常用优化。
2. **数独/填数类搜索**：同一类"DFS + 行/列/块标记 + 剪枝"，模板完全通用。
3. **求所有解输出**：graph 数组改成记录到 `vector<vector<int>>`。

---

## 九、知识点小结

> **DFS 回溯三步曲：① 尝试放置（打标）→ ② 递归下一层 → ③ 还原（取消标）。**
> 剪枝的本质：**用数组记录"已占用"状态，在递归前 O(1) 判断冲突，砍掉不可能的分支。**
