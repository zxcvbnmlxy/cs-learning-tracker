# P1141 01迷宫 题解

> 2026-08-16 完成 | BFS + 连通块预处理（离线预处理 → O(1) 查询）
> 一句话定位：**每个格子的答案 = 它所在连通块的大小，连通块一次性搜完，询问直接查表。**

---

## 一、题目翻译成图论

把每个格子看成一个**点**，"相邻且值不同"的两个格子**连一条边**：

- 0 能走到相邻的 1，1 能走到相邻的 0 → **边只连接值不同的相邻点**
- 问"从一个格子能到多少格（含自己）" → **这个点所在连通块里有多少个点**

```
01
10
```
四个格子互相连通（0↔1 都相邻），所以 (1,1) 和 (2,2) 的答案都是 4。

---

## 二、核心洞察：可达性是等价关系（这题的钥匙）

如果 A 能到 B，那么 **A 能到达的集合 = B 能到达的集合**。

原因：
1. 移动规则**对称**：能过去就能回来（0→1 和 1→0 都允许）；
2. 所以凡是 B 能到的，A 通过 B 也能到；凡是 A 能到的，B 也能到。

结论：互相可达的格子构成**等价类（连通块）**，**块内每个格子的答案都相同**。

> 问题降维：**给每个格子标上所属连通块的编号 + 统计每个块的大小**。

---

## 三、为什么要预处理（本题真正的考点）

| | 暴力 | 预处理 |
|---|---|---|
| 做法 | 每个询问现场 BFS 一次 | 所有连通块一次性搜完 |
| 复杂度 | O(m·n²) ≈ 10⁵ × 10⁶ = **10¹¹** ❌ | 预处理 O(n²) + 每次询问 O(1) ✅ |

m 最大 **10⁵**，暴力必 TLE。正确套路：

> **先离线把所有连通块搜完，再在线 O(1) 查表** —— "图论建图 + 记忆化查询"的经典思想。

---

## 四、算法流程

1. 扫全盘，遇到 `belong==0`（未访问）的格子 → 以它为起点 BFS 扩散整个连通块；
2. 入队即打标：`belong[x][y] = id`，同时 `size++`；
3. BFS 结束存块大小：`block_size[id] = size`；
4. 每个询问 `(x,y)`：转 0 下标后直接 `cout << block_size[belong[x][y]]`。

---

## 五、代码（重点注释版）

```cpp
#include<bits/stdc++.h>
using namespace std;
const int MAXN=1005;
int belong[MAXN][MAXN];      // 每个坐标所属的连通块编号（0=未访问）
int block_size[MAXN*MAXN];   // 每个连通块的大小（块内任意格子的答案都相等）
char graph[MAXN][MAXN];
vector<pair<int,int>>dir={{-1,0},{0,-1},{0,1},{1,0}};
int n,m;

// id：连通块编号
void bfs(int startx,int starty,int id){
    queue<tuple<int,int,char>>q;
    q.push({startx,starty,graph[startx][starty]});
    belong[startx][starty]=id;        // 起点打标
    int size=0;
    while(!q.empty()){
        auto [x,y,color]=q.front();
        size++;
        q.pop();
        for(auto [dx,dy]:dir){
            int nx=dx+x,ny=dy+y;
            // 移动三条件：①棋盘内 ②值不同(=边的定义) ③未访问
            if(nx>=0&&ny>=0&&ny<n&&nx<n&&graph[nx][ny]!=color&&belong[nx][ny]==0){
                q.push({nx,ny,graph[nx][ny]});
                belong[nx][ny]=id;    // 关键：入队即打标，防止重复入队
            }
        }
    }
    block_size[id]=size;
}

int main(){
    cin>>n>>m;
    for(int i=0;i<n;i++)
        for(int j=0;j<n;j++)
            cin>>graph[i][j];          // 字符之间无空格，cin>>char 逐字符读

    int id=0;
    for(int i=0;i<n;i++)               // 离线预处理：所有连通块一次搜完
        for(int j=0;j<n;j++)
            if(belong[i][j]==0){
                id++;
                bfs(i,j,id);
            }

    for(int i=0;i<m;i++){              // 在线 O(1) 查询
        int x,y;
        cin>>x>>y;
        x--,y--;                       // 1-index → 0-index
        cout<<block_size[belong[x][y]]<<endl;
    }
    return 0;
}
```

---

## 六、代码里三处关键细节

1. **入队即打标**（`belong[nx][ny]=id` 紧贴 push 写）：
   如果改成"出队才打标"，同一个格子会被多个邻居反复入队 → 退化成 O(n⁴)。
   这是 BFS 最经典的坑，**打标时机 = 入队时**。

2. **`graph[nx][ny]!=color` 把"边的定义"直接写进 BFS 判定**：
   不用单独建图，四方向即时判定，代码最简洁。

3. **`belong==0` 兼当"未访问"标记**：编号从 1 开始，省一个 visited 数组。

4. **队列存 `color`**：出队时不用再查 `graph[x][y]`，结构化绑定 `auto [x,y,color]` 直接取。

## 七、复杂度

| | 预处理 | 每次询问 | 总计 |
|---|---|---|---|
| 时间 | O(n²) | O(1) | O(n² + m) |
| 空间 | O(n²) | — | O(n²) |

## 八、变式思考（举一反三）

1. **移动规则改成"只能走到值相同"**：判定 `!=` 改成 `==`，框架完全不动。
2. **棋盘是 n×m 矩形**：边界判定用两个独立的 n、m，别只比一个。
3. **询问变成在线动态连边**：BFS 离线做不了 → 用**并查集**（和之前学的带权并查集接上）。
4. **答案要输出路径而不是数量**：BFS 额外记录 `pre` 数组回溯。

---

## 九、知识点小结

> **BFS + 连通块 = "每个点的问题 → 整个块共享答案"**。
> 识别特征：多组询问、每次询问本质相同、m 很大 → **先预处理所有块，再 O(1) 查表**。
>
> 等价关系三性质（自反、对称、传递）是判断"能不能合并答案"的通用工具：
> 只要问题满足这三条，就能把点分成等价类、按类预处理。
