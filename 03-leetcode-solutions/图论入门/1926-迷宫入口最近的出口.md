[1926. 迷宫中离入口最近的出口](https://leetcode.cn/problems/nearest-exit-from-entrance-in-maze/description/)
# 思路

bfs(找最短路径)，走过的记录为visited(优化为在maze将该点改为墙)，用队列q,保存当前坐标和路径距离

# 复杂度

- 时间复杂度: $O(mn)$
- 空间复杂度: $O(mn)$

# Code
```C++ []
class Solution {
public:
    int nearestExit(vector<vector<char>>& maze, vector<int>& entrance) {
        int n=maze.size(),m=maze[0].size();
        queue<tuple<int,int,int>>q;
        vector<pair<int,int>>dir={{-1,0},{0,-1},{0,1},{1,0}};
        int x0=entrance[0],y0=entrance[1];
        int d=0;
        q.push({x0,y0,d});
        maze[x0][y0]='+';
        while(!q.empty()){
            auto [x,y,d]=q.front();
            q.pop();
            for(auto [dx,dy]:dir){
                int nx=dx+x;
                int ny=dy+y;
                if(nx>=0&&nx<=n-1&&ny>=0&&ny<m&&maze[nx][ny]=='.'){
                    if(nx==0||nx==n-1||ny==0||ny==m-1){
                        return d+1;
                    }
                    q.push({nx,ny,d+1});
                    maze[nx][ny]='+';
                }
            }
        }
        return -1;
    }
};
```
