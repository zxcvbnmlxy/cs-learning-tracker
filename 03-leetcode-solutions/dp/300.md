[300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/description/)
# 思路
该算法的核心是维护一个dp数组，其中dp[k]表示长度为k+1的最长严格递增子序列的最小尾部值（dp数组从 0 开始索引）。
核心思想：
1)对于相同长度的递增子序列，其尾部值越小，后续元素越容易接在它后面，形成更长的子序列。因此，我们要为每个长度的子序列，尽可能维护一个更小的尾部值。
2)处理每个元素nums[i]时的逻辑：
若nums[i]大于dp数组的最后一个元素（即当前最长子序列的尾部值），说明可以直接接在后面，形成更长的子序列。此时将nums[i]追加到dp的末尾，最长子序列长度 + 1。
若nums[i]小于等于dp数组的最后一个元素，则需要在dp数组中，找到第一个大于等于nums[i]的位置pos（利用dp数组的有序性，用二分查找实现），然后将dp[pos]更新为nums[i]。
这样做的目的是：用nums[i]替换掉长度为pos+1的子序列的当前尾部值，让它变得更小，从而为后续元素提供更多的可能性。
3)时间复杂度分析：
遍历数组的时间为 O (n)，每次二分查找的时间为 O (log n)，因此整体时间复杂度为 O (n log n)
代码如下
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n=nums.size();
        if(n<=1)return n;
        int s=1;
        vector<int>dp(n+1,0);
        dp[1]=nums[0];
        for(int i=1;i<n;i++){
            if(dp[s]<nums[i]){
                dp[++s]=nums[i];
            }
            else{
                int l=1,r=s,pos=0;
                while(l<=r){
                    int mid=(l+r)/2;
                    if(nums[i]>dp[mid]){
                       pos=mid;
                        l=mid+1;
                    }
                    else{
                         r=mid-1;
                    }
                }
                dp[pos+1]=nums[i];
            }
        }
        return s;
    }
};
