[2770. 达到末尾下标所需的最大跳跃次数]
(https://leetcode.cn/problems/maximum-number-of-jumps-to-reach-the-last-index/description/)
动态规划，
1）确定dp数组含义：dp[i]表示跳转到下标i的最大步数；
2）确定状态转移方程：dp[j]=max(dp[j],dp[i]+1);要求nums[j]>=nums[i]-target&&nums[j]<=nums[i]+target
3)初始化dp数组：dp(n,-1);dp[0]=0;
4)确定遍历顺序：题目要求i跳到j ,0<i<j<n,还有根据dp数组含义应该是i=0;i<n;i++；也可以倒着遍历，但dp数组含义发生改变，dp[i]表示从i到n-1的最大步数
5)举例验证
代码如下
class Solution {
public:
    int maximumJumps(vector<int>& nums, int target) {
        int n=nums.size();
       vector<int>dp(n,-1);
       dp[0]=0;
       for(int i=0;i<n;i++){
        if(dp[i]==-1)continue;
            for(int j=i+1;j<n;j++){
                if(abs(nums[j]-nums[i])<=target){
                    dp[j]=max(dp[j],dp[i]+1);
                }
            }
       }
       return dp[n-1];
    }
};
