# 思路

贪心+定长滑动窗口

# 解题过程

答案就是原来满意的顾客数+使用特殊技能之后原来不满意的顾客变为满意数；
双指针left，i维护窗口大小minutes，贪心计算在minutes内最大的不满意顾客数

# 复杂度

- 时间复杂度: $O(n)$
- 空间复杂度: $O(1)$



# Code
```C++ []
class Solution {
public:
    int maxSatisfied(vector<int>& customers, vector<int>& grumpy, int minutes) {
        int max_s=0,ans=0;
        for(int i=0;i<customers.size();i++){
            if(grumpy[i]==0)ans+=customers[i];
        }
        int s=0;
        for(int i=0;i<customers.size();i++){
            int left=i-minutes+1;
            if(grumpy[i]==1)s+=customers[i];
            if(left<0)continue;
            max_s=max(max_s,s);
            if(grumpy[left]==1)s-=customers[left];
        }
        return max_s+ans;
    }
};
