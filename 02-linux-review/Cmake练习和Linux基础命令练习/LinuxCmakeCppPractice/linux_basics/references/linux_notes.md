# Linux 基础命令 — 学习笔记

## 一、grep — 文本搜索

```bash
grep "模式" 文件名      # 搜索匹配的行
grep -v "模式" 文件名   # 反向匹配（不包含的）
grep -c "模式" 文件名   # 计数
grep -n "模式" 文件名   # 显示行号
grep -E "模式" 文件名   # 扩展正则
grep -i "模式" 文件名   # 忽略大小写
```

## 二、sed — 流编辑器

```bash
sed 's/旧/新/' 文件名       # 替换每行第一个匹配
sed 's/旧/新/g' 文件名      # 全局替换
sed -n 's/旧/新/p' 文件名   # 仅显示被替换的行
sed '/模式/d' 文件名        # 删除匹配的行
sed '1s/.*/新内容/' 文件名  # 替换第1行整行
```

**注意：** sed 默认不改原文件，只改输出。加 `-i` 才直接修改文件。

## 三、awk — 文本分析

```bash
awk '{print $1, $2}' 文件名      # 打印第1、2列
awk 'NR>1 {print $1}' 文件名     # 跳过表头（跳过第1行）
awk '$2>=90 {print $1}' 文件名   # 条件过滤
awk 'BEGIN {print "表头"} {print $1} END {print "结束"}' 文件名
awk '{sum+=$1} END {print sum}' 文件名  # 求和
```

**awk 内置变量：** `$1`~`$N` 各列、`NR` 行号、`NF` 列数、`FS` 列分隔符

## 四、权限与链接

```bash
chmod 755 文件    # 数字模式：rwxr-xr-x
chmod u+x 文件    # 字母模式：所有者加执行
chmod g-r 文件    # 字母模式：同组去掉读
chmod o=r 文件    # 字母模式：其他人设为只读

ln -s 原文件 链接  # 软链接（快捷方式）
ln 原文件 链接     # 硬链接（同一份数据）
```

### 权限串解读

```
-rwxr-xr-x
↑↑↑↑↑↑↑↑↑↑
│││││││││└ 第9位: 其他人-执行 (x/-)
││││││││└─ 第8位: 其他人-写   (w/-)
│││││││└── 第7位: 其他人-读   (r/-)
││││││└─── 第6位: 同组-执行   (x/-)
│││││└──── 第5位: 同组-写     (w/-)
││││└───── 第4位: 同组-读     (r/-)
│││└────── 第3位: 所有者-执行 (x/-)
││└─────── 第2位: 所有者-写   (w/-)
│└──────── 第1位: 所有者-读   (r/-)
└───────── 第0位: 文件类型 (-=文件, d=目录, l=链接)
```

### 常见权限值

| 数字 | 权限 | 用途 |
|------|------|------|
| 644  | rw-r--r-- | 普通文件默认 |
| 755  | rwxr-xr-x | 脚本/可执行文件 |
| 700  | rwx------ | 私有文件 |
| 600  | rw------- | SSH 私钥 |
| 777  | rwxrwxrwx | 完全开放（不推荐） |

### 数字速记

```
r=4  w=2  x=1
755 = r(4)+w(2)+x(1) | r(4)+x(1) | r(4)+x(1)
    =       7       |     5     |     5
```

### ⚠️ WSL 注意点

在 WSL 中 `/mnt/d/` 路径下（Windows 文件系统）chmod 可能不生效，需要在 Linux 原生文件系统（如 `~/`）下练习。

## 常用命令组合

```bash
ps aux | grep 进程名       # 查找进程
chmod +x script.sh && ./script.sh  # 加权限并运行
ls -la | awk '{print $1, $9}'  # 只显示权限和文件名
```
