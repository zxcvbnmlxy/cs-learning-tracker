数据查询语言 DQL
数据操作语言 DML
数据定义语言 DDL
数据控制语言 DCL
事务控制语言 TCL -> 确保DML操作的表及时更新

注意：DML、DDL、DCL、TCL都是SQL语言的子集，DQL是SQL语言的查询部分。
    DML：主要针对表中的数据
    DDL：主要针对数据库对象
    DCL：主要针对数据库用户权限的控制
    TCL：主要针对事务的控制
SWL不区分大小写，可以多行或者单行，用分号结尾;
创建数据库
    create database    --创建数据库关键字
    数据库名    
    character set      --指定默认编码 
    utf8 ;             --指定编码

删除数据库
    drop database      --删除数据库关键字
    数据库名

查看数据库
    show databases;    --查看所有数据库
    show create database 数据库名;  --查看指定数据库的创建语句


注意：在创建数据库时，指定的编码格式必须是MySQL支持的编码格式，否则会报错。
注意：在删除数据库时，必须确保数据库中没有正在使用的表，否则会报错。

注意：在创建表前，必须先选择数据库进行操作;选择语句：
    use 数据库名;      --选择数据库

创建表
    create table        --创建表关键字
    表名                --指定表名
    (                   --开始定义字段
        字段名 数据类型 [约束条件],  --定义字段及其数据类型和约束条件
        字段名 数据类型 [约束条件],
        ...
    )                   --结束定义字段
    [表选项];          --可选的表选项，如存储引擎、字符集等

    create table 
    表名(列名 数据类型[约束条件（可以没有）],列名 数据类型[约束条件 （可无）],....) ;

删除表
    drop table        --删除表关键字
    表名 ;

修改表名
    alter table      --修改表关键字
    表名              --指定要修改的表名
    rename           --指定新的表名关键字
    新表名; 

改列名
    alter table      --修改表关键字
    表名
    change column      --修改列关键字
    旧列名
    新列名 数据类型[约束条件（可无）];

改列类型
    alter table      --修改表关键字
    表名
    modify
    列名 类型;

添加新列
    alter table    --修改表关键字
    表名
    add column        --添加列关键字
    列名 数据类型;

删除指定列
    alter table     --修改表关键字
    表名
    drop column      --删除列关键字
    列名;

指定主键约束
    alter table     --修改表关键字
    表名
    add primary key(列名)
注意:
    1.主键约束的列名是唯一的  2.主键约束的值不能为null  3.主键约束的列名可以是单列，也可以是多列组合 4.每一表中只能有一个主键约束
    
指定外键约束
    alter table     --修改表关键字
    表名
    add constraint 外键约束名 foreign key(列名) references 关联表名(关联列名);
注意:
    1. 外键约束名可以自定义，也可以不写，MySQL会自动生成一个外键约束名。
    2. 外键约束的列名必须是关联表的主键或唯一键。
    3. 外键约束的列名和关联表的列名的数据类型必须一致。
